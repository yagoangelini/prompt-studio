# Instruções para o Claude Code: boilerplate de app Electron com dois modos

Crie um aplicativo Electron completo com as seguintes especificações:

## Requisitos principais

### 1. Operação em dois modos
- **Modo desktop**: aplicativo tradicional em janela (1200x800px)
- **Modo barra de menus**: pequena janela suspensa aberta a partir da bandeja do sistema/barra de menus (400x600px)
- Alternar entre os modos pelo menu de contexto
- Salvar a preferência de modo no banco de dados
- Forçar o modo desktop na primeira execução, para garantir que a janela fique visível

### 2. Integração com banco de dados
- Usar o SQLite3 como banco de dados principal
- Criar um módulo de inicialização do banco de dados com:
  - Gerenciamento de conexão
  - Scripts de criação de tabelas
  - Suporte a migrações
- Armazenar o banco de dados no diretório userData do app
- Incluir um módulo com as operações CRUD básicas

### 3. Estrutura do projeto
```
project-name/
├── main.js                 # Processo principal do Electron
├── package.json           # Dependências e scripts
├── assets/
│   └── icon.png          # Ícone do app (PNG 256x256)
├── scripts/
│   ├── run.sh            # Script de execução rápida (Unix)
│   ├── run.bat           # Script de execução rápida (Windows)
│   ├── build-app.sh      # Script de build do instalador (Unix)
│   └── build-app.ps1     # Script de build para Windows (PowerShell)
├── src/
│   ├── database/
│   │   ├── init.js       # Inicialização do banco de dados
│   │   └── queries.js    # Operações no banco de dados
│   └── renderer/
│       ├── index.html    # Janela principal
│       ├── menubar.html  # Janela da barra de menus
│       ├── renderer.js   # Lógica da janela principal
│       ├── menubar-renderer.js # Lógica da barra de menus
│       ├── styles.css    # Estilos da janela principal
│       └── menubar-styles.css # Estilos da barra de menus
└── README.md            # Documentação
```

### 4. Configuração do package.json
Inclua estas dependências:
```json
{
  "dependencies": {
    "electron-store": "^10.1.0",
    "sqlite3": "^5.1.7"
  },
  "devDependencies": {
    "electron": "^37.2.5",
    "electron-builder": "^26.0.12"
  },
  "scripts": {
    "start": "electron .",
    "dev": "electron . --dev",
    "run:unix": "bash ./scripts/run.sh",
    "run:win": "scripts\run.bat",
    "build:unix": "bash ./scripts/build-app.sh",
    "build:win": "powershell ./scripts/build-app.ps1",
    "build": "electron-builder",
    "build:mac": "electron-builder --mac",
    "build:win": "electron-builder --win",
    "build:linux": "electron-builder --linux"
  }
}
```

### 5. Recursos do processo principal (main.js)
- Criar as janelas do modo desktop e do modo barra de menus
- Ícone na bandeja do sistema com menu de contexto
- Handlers IPC para as operações de banco de dados
- Funcionalidade de alternância entre os modos do app
- Gerenciamento adequado das janelas (lógica de mostrar/ocultar)
- Configuração do nome e dos metadados do app

### 6. Esquema do banco de dados
Crie as tabelas iniciais:
```sql
-- Tabela de configurações do app
CREATE TABLE IF NOT EXISTS settings (
    key TEXT PRIMARY KEY,
    value TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Tabela de dados de exemplo
CREATE TABLE IF NOT EXISTS items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    description TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 7. Recursos do processo de renderização (renderer)
- **Janela principal**: interface completa, com navegação
- **Janela da barra de menus**: compacta, apenas com os recursos essenciais
- Estilos compartilhados com variáveis CSS
- Design responsivo para diferentes tamanhos de janela
- Comunicação IPC com o processo principal

### 8. Integração com a bandeja do sistema
- Criação programática do ícone (um símbolo simples de gráfico)
- Menu de contexto com:
  - Mostrar/Ocultar o app
  - Alternar modo (Desktop ↔ Barra de menus)
  - Sair do aplicativo
- Imagem do tipo template (template image) para compatibilidade com os modos claro e escuro
- Tratamento adequado dos eventos de clique

### 9. Scripts de build

#### run.sh (desenvolvimento, Unix)
```bash
#!/bin/bash
# Execução rápida em desenvolvimento para Unix
# Verifica as dependências, instala se necessário e inicia o app
```

#### run.bat (desenvolvimento, Windows)
```bat
@echo off
REM Execução rápida em desenvolvimento para Windows
REM Verifica as dependências, instala se necessário e inicia o app
```

#### build-app.sh (produção, Unix)
```bash
#!/bin/bash
# Script de build de produção para Unix
# Cria pacotes distribuíveis para a plataforma atual
```

#### build-app.ps1 (produção, Windows PowerShell)
```powershell
# Script de build de produção para o Windows PowerShell
# Cria pacotes distribuíveis para a plataforma atual
```

### 10. Tratamento de erros
- Erros de conexão com o banco de dados
- Dependências ausentes
- Problemas específicos de cada plataforma
- Alternativas (fallbacks) adequadas para todos os recursos

### 11. Compatibilidade entre plataformas
- **macOS**: instalador DMG e ícones .icns adequados
- **Windows**: instalador NSIS e ícones .ico
- **Linux**: pacotes AppImage e .deb

### 12. Recursos de desenvolvimento
- Hot reload no modo de desenvolvimento
- Logs no console para depuração
- Error boundaries e recuperação de erros
- Limpeza adequada ao encerrar o app

## Observações de implementação

1. **Inicie com o modo desktop forçado** para garantir que a janela do app fique visível
2. **Use caminhos absolutos** em todas as referências a arquivos
3. **Inclua um registro de erros abrangente** para facilitar a solução de problemas
4. **Teste nas arquiteturas ARM64 e x86_64**
5. **Siga as boas práticas de segurança do Electron**
6. **Inclua os metadados adequados do app** (nome, versão, descrição)

## Templates de arquivos necessários

1. **main.js** - processo principal completo, com todos os recursos
2. **Módulos de banco de dados** - init.js e queries.js com CRUD completo
3. **Templates HTML** - os dois tipos de janela, com a estrutura adequada
4. **Arquivos CSS** - estilos limpos e modernos
5. **package.json** - completo, com todas as dependências e scripts
6. **Scripts de shell** - run.sh, run.bat, build-app.sh e build-app.ps1 funcionando
7. **README.md** - documentação completa e instruções de configuração

## Checklist de testes

Após a implementação, verifique se:
- [ ] O app inicia no modo desktop com a janela visível
- [ ] O banco de dados é criado com sucesso no diretório userData
- [ ] O ícone da bandeja do sistema aparece e funciona
- [ ] A alternância de modos funciona corretamente
- [ ] Os scripts de build geram instaladores funcionais
- [ ] Toda a comunicação IPC funciona
- [ ] O app trata os erros de forma adequada
- [ ] Os dois tipos de janela são renderizados corretamente

## Conceito de app de exemplo
Crie um app simples de "Gerenciador de tarefas" que demonstre todos os recursos:
- Adicionar/editar/excluir tarefas (operações no banco de dados)
- Visualizar as tarefas nos modos desktop e barra de menus
- Configurações do comportamento do app
- Notificações/alertas de tarefas

Este boilerplate deve resultar em um aplicativo Electron totalmente funcional e pronto para produção, que sirva de base para qualquer projeto de app desktop/barra de menus.
